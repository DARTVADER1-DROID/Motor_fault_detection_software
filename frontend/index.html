📋 FIRMWARE INTEGRATION REFERENCE
Poll Commands GET /motor/{id}/command Call at 500ms–2s interval. Returns next queued command or NONE.
Push Sensor Data POST /update JSON body: {"motor_id", "voltage", "current", "speed", "temperature"}
Connection Timeout 3 seconds Motor marked TIMEOUT if no /update call within window.
Valid Sensor Ranges V: 0–20 | A: 0–15 | RPM: 0–3500 | °C: −10–120 Inputs are clamped server-side. Shell temperature only — not winding.
Auto-Stop Faults STALL | THERMAL_RUNAWAY | WINDING_SHORT CRITICAL faults trigger immediate state→FAULT. Requires power cycle to recover.
